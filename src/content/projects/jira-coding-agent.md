I took [Jira Coding Agent](https://support.atlassian.com/jira-software-cloud/docs/what-is-the-jira-coding-agent/) from zero to general availability (GA), leading a team of 15 engineers. The agent used the context already captured in a Jira issue to plan and generate a code change.

## Success

Jira now has its own coding agent, a critical piece of the larger AI SDLC story and provides a frontier quality coding agent out of the box with any paid Jira cloud subscription. Early customer insights saw some large companies combining Jira automation with Jira Coding Agent to automate away repetitive work like security vulnerabilities.

## My contribution

I led the engineering team through the build and launch. Our scope covered the platform, our own agent harness, the product experience inside Jira, and integration with Rovo.

## What we built

- **A new sandbox platform** to support the coding agent.
- **Our own agent harness**, built alongside the platform and product experience.
- **New product UX inside Jira**, adhering to the design guidelines.
- **Integration with Rovo**, connecting the coding agent with the wider product.

## Learnings

- Ideal cloud environments for businesses
- Processes in the SDLC need tuning to become truly AI native
- The value of using your own products
