Rovo Dev CLI brings Atlassian’s agentic coding to the terminal, alongside the coding agent in Jira as part of the wider Rovo Dev story.

## Success

Internal adoption of Rovo Dev CLI reached over 2000 DAU. Externally Rovo Dev CLI usage accounted for the majority of Rovo Dev subscriptions.

## My contribution

Engineering manager within the team of 15 engineers building Atlassian’s Rovo Dev CLI and Rovo Dev in Jira. I worked in a triad of PM, design, EM and architect. We only had 4 engineers on this project but we moved fast and shipped value daily. At Team ’25 US and EU I presented live demos to hundreds of potential customers and set up the first Rovo Dev CLI workshop.

## What we built

- **A terminal-native coding agent** for developers who live at the command line.
- **Part of the Rovo Dev family**, sharing the agent story across the CLI and Jira.
- **A state-of-the-art evaluation platform** to test that changes to the harness were producing higher quality outputs.
